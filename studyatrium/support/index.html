Support für StudyAtrium

StudyAtrium ist eine App für einen Server, den Sie oder jemand, den Sie kennen, betreiben. Diese Seite sagt Ihnen, wo Sie Hilfe bekommen.

Schreiben Sie an diese Adresse bei Fragen zur App, bei Problemen, die Sie mit der folgenden Anleitung nicht lösen können, und für Datenschutzanfragen (siehe Datenschutzerklärung). Nennen Sie bitte die App-Version (Einrichtung, „Über“), Ihr Gerät und die iOS-Version und, wenn Sie sie kennen, die Version Ihres Servers. Der Herausgeber betreibt keinen StudyAtrium-Server für andere. Stimmt etwas mit den Daten auf Ihrem Server, mit dessen Erreichbarkeit oder mit dessen Datenschutzerklärung nicht, ist der Betreiber Ihres Servers der richtige Ansprechpartner.

Einrichtungsanleitung und Fehlermeldungen

  • Einrichtungsanleitung (englisch): wie Sie einen eigenen StudyAtrium-Server betreiben und die App damit verbinden.
  • GitHub Issues: Fehler melden oder Funktionen vorschlagen. Das ist öffentlich: Schreiben Sie dort keine personenbezogenen Daten, Passwörter oder Serveradressen, die privat bleiben sollen. Dafür brauchen Sie ein GitHub-Konto.
  • Quellcode und Dokumentation von Server und Apps.

Häufige Fragen

Was brauche ich, um die App zu nutzen?

Einen eigenen StudyAtrium-Server (oder einen, den jemand für Sie betreibt und zu dem Sie Zugang haben). Es gibt keinen zentralen StudyAtrium-Dienst und kein Konto beim Herausgeber. Beim ersten Start geben Sie die Adresse Ihres Servers ein und melden sich dort an; die App verbindet sich nur mit diesem Server (und mit Apple für Mitteilungen). Ohne Server lässt sich die App nicht nutzen. Die Einrichtungsanleitung erklärt, wie Sie einen aufsetzen.

Kann ich es ohne eigenen Server ausprobieren?

Ja: Geben Sie studylife-demo.lktec.org als Serveradresse ein. Das ist eine öffentliche Demo mit Beispieldaten, die nur lesen lässt; Änderungen, Registrierung und Kontolöschung sind dort abgeschaltet. Einzelheiten stehen in Abschnitt 6 der Datenschutzerklärung.

Wo liegen meine Daten, und wer kann sie sehen?

Auf Ihrem Server und, als Zwischenspeicher, auf Ihrem Gerät. Verantwortlich dafür ist der Betreiber des Servers; der Herausgeber der App erhält nichts davon. Siehe die Datenschutzerklärung.

Bekomme ich mit einem selbst betriebenen Server Push-Mitteilungen?

Nicht von Ihrem Server. Apple nimmt Push-Nachrichten für diese App nur an, wenn sie mit einem Schlüssel signiert sind, den der Herausgeber besitzt, und dieser Schlüssel ist nur auf der Instanz eingerichtet, die für Apples App-Prüfung dient. Ein Server, den Sie selbst betreiben, kann deshalb keine Push-Mitteilungen und keine Fern-Aktualisierungen der Live-Aktivität an die App-Store-Version der App senden. Das ist eine Grenze von Apples Push-System, keine Einstellung, die Sie übersehen haben.

Das bekommen Sie mit einem selbst betriebenen Server:

  • Erinnerungen, die die App selbst auf Ihrem Gerät plant (zum Beispiel für geplante Lerneinheiten), auch ohne Verbindung zum Server, sofern Sie Mitteilungen erlaubt haben.
  • Live-Aktivitäten, Widgets, Kurzbefehle und die Apple-Watch-App, die den Stand beim letzten Kontakt der App mit Ihrem Server zeigen. Die Live-Aktivität des Lern-Timers aktualisiert sich, solange die App offen ist oder im Hintergrund läuft, aber nicht per Fern-Push bei geschlossener App.
  • Browser-Mitteilungen, wenn Sie die Weboberfläche Ihres Servers im Browser nutzen: Sie laufen über den Push-Dienst Ihres Browsers und hängen nicht vom Schlüssel für die App bei Apple ab.

Berichte, Hinweise und andere Nachrichten, die Ihr Server als Push-Mitteilung senden würde, sehen Sie in der App, wenn Sie sie öffnen, nicht als Push-Nachricht auf dem Sperrbildschirm.

Welche Serverversion brauche ich?

Halten Sie Ihren Server aktuell. Eine neuere App kann Funktionen nutzen, die ein alter Server noch nicht bietet. Die Versionshinweise auf GitHub nennen die Änderungen.

Was passiert mit meinen Daten auf dem Gerät, wenn ich mich abmelde oder mein Konto lösche?

Die App entfernt ihre lokalen Kopien: Zwischenspeicher, Daten für Widgets und Apple Watch, Spotlight-Einträge, exportierte Dateien, noch nicht gesendete geteilte Texte und zugestellte Mitteilungen. Abschnitt 3.3 der Datenschutzerklärung listet auf, was entfernt wird. Das Konto selbst löschen Sie in der App unter „Einrichtung“ (Abschnitt 5.1).
